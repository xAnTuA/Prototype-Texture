# Prototype-Texture

Provides fast, customizable and object scale independent prototype texture.

Ideal for quick gray-boxing without worrying about texture scale.

NOTE: This project uses triplanar projection, witch means it is great for spatial awareness,
but isn't for distance measurement as distance between points on texture can vary.

Comes with 5 pre-made colors and 2 textures.

To add texture, make sure the element you want to be colorized are transparent.
